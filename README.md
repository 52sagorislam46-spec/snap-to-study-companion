# Snap To Study Companion

আমার একটি জিনিস সম্পর্কে জানা দরকার বা সেটা তুমি করতে পারবা কি না বলো। যেমন কাজ টি হলো আমার কালকে পরিক্ষা তো আমি আগে পিছনে কোনো পড়ালেখা করি নাই বা আমার কাছে কোনো বই পুস্তক ও নেই আমি কতগুলো সাজেশন পেয়েছি তা অনেকগুলো যা একসাথে বা একরাএে পড়ে শেষ করা সম্ভব না এই জন্য এমন একটা অ্যাপ বানানো কি সম্ভব না যেই অ্যাপে সব সাজেশন এর ছবি একসাথে ১০ থেকে২০ টা ছবি মার্ক করে দিলে সেই সাজেশন অনুযায়ী সর্ট করে করে আমাকে পরিক্ষায় যেনো পাস করা যা সেই অনুযায়ী প্রশ্ন তৈরি করে দিবে এবং উওর ও দিবে আবার সেটা আমি না পরে এআই ভয়েস ও শোনাইয়া দিতে পারে। যদি কারো কাছে কোনো সাজেশন না থাকে তাহলে সে কি করবে, সংক্ষিপ্ত প্রশ্ন, মাঝারি বর্ণনামূলক প্রশ্ন আর বর্ণনামূলক প্রশ্নও থাকবে। Voice ID হলো Cartesia-এর: eaf6e598-18d5-4895-8b86-dc4ac7ba1c07। এখন শুধু Cartesia-এর voice API key, Gemini API key, এবং Groq API key-এর জন্য secure secret entry চাই। কোনো অ্যাপ ফিচার বা বিল্ড শুরু করো না। আমি কীগুলো যোগ করার পর শুধু নিশ্চিত করে থেমে থাকবে; আমি পরে স্পষ্ট করে কাজ শুরু করতে বললেই অ্যাপ বানাবে.
